OVERVIEW
================================================================================

FAMILY LOGIN
  Profile owner (member) can add up to 3 family members (parent/sibling).
  Family logs in with their OWN email + password.
  They browse profiles on behalf of the member — READ ONLY.

  ✓ Allowed: search, view profiles, shortlist browse, dashboard
  ✗ Blocked: send interest, chat, edit profile, change settings, payment, upload

SETTINGS PAGE (Owner only)
  Privacy toggles, notifications, family login management,
  change password, premium renewal reminders, deactivate account.


================================================================================
PART 1 — FAMILY LOGIN
================================================================================

--- How it works ---

1. Member (owner) → Settings → Add family login (name, email, password, relationship)
2. Family member → Login screen → "Family Login" tab
3. Family enters THEIR email + password (not member's email)
4. JWT token issued with role = "FAMILY"
5. App shows banner: "Family Login — browsing {ownerName}'s profile"
6. All browse APIs use owner user id from token


--- POST Family Login ---

POST /api/flutter/auth/family-login
Body:
{
  "email": "father@gmail.com",
  "password": "family123"
}

Success 200:
{
  "success": true,
  "token": "<JWT>",
  "user": {
    "id": "<owner_user_id>",
    "name": "Ramesh (Parent)",
    "email": "father@gmail.com",
    "role": "FAMILY",
    "isFamilyLogin": true,
    "familyAccessId": "uuid",
    "memberName": "Ramesh",
    "relationship": "Parent",
    "ownerName": "Rahul Sharma",
    "ownerId": "<owner_user_id>",
    "isPremium": true,
    "premiumPlan": "GOLD",
    "adminVerified": true,
    "verificationBadge": false,
    "freeTrialActive": false,
    "freeTrialExpiry": null
  }
}

Errors:
  400 — email/password missing
  401 — invalid family credentials
  403 — owner account inactive


--- JWT payload (store in app state) ---

After family login, save:
  token
  user.role === "FAMILY"
  user.isFamilyLogin === true
  user.ownerName
  user.id === owner's user id (used for all API calls)


--- Flutter Login Screen UI ---

Two tabs on login page:
  [ Member Login ]  [ Family Login ]

Member tab → POST /api/flutter/auth/login
Family tab → POST /api/flutter/auth/family-login

After family login success:
  - Navigate to Dashboard (not onboarding)
  - Show persistent banner at top:
    "👨‍👩‍👧 Family mode — browsing Rahul's profile (read-only)"
  - Hide bottom nav items: Chat, Interests send, Premium purchase, Settings edit


--- What family CAN do ---

GET  /api/flutter/search
GET  /api/flutter/matches
GET  /api/flutter/profile/{id}
GET  /api/flutter/dashboard
GET  /api/flutter/shortlist        (view only)
GET  /api/flutter/profile-views
GET  /api/flutter/recently-viewed
GET  /api/flutter/settings         (read-only — readOnly: true in response)


--- What family CANNOT do (403 FAMILY_READONLY) ---

POST /api/flutter/interest              → send interest
POST /api/flutter/chat                  → chat
GET  /api/flutter/chat                  → chat list
PUT  /api/flutter/profile               → edit profile
PATCH /api/flutter/settings             → change settings
POST /api/flutter/payment/*             → payment
POST /api/flutter/upload/*              → uploads
POST /api/flutter/auth/change-password  → password

Error response:
{
  "error": "Family login cannot send interests",
  "code": "FAMILY_READONLY"
}


--- Flutter UI rules for family mode ---

On profile detail screen:
  - Hide "Send Interest" button
  - Hide "Chat" button
  - Show info card:
    "Family browse mode — only the profile owner can send interests."

On dashboard:
  - Show family banner (blue)
  - Hide "Edit Profile" CTA

On settings:
  - Either hide Settings tab entirely for family
  - OR show read-only message: "Settings can only be changed by profile owner"

Detect family mode globally:
  if (auth.user.isFamilyLogin == true) { ... disable actions ... }

}


--- PATCH save settings (owner only) ---

PATCH /api/flutter/settings
Headers: Authorization: Bearer <token>

Body (send only changed sections):
{
  "privacy": {
    "hidePhone": true,
    "hidePhoto": false,
    "profileVisible": true,
    "showOnlineStatus": false
  },
  "notifications": {
    "notifyInterest": true,
    "notifyMessage": true,
    "notifyProfileView": false,
    "notifyMarketing": false
  },
  "subscription": {
    "autoRenew": true
  }
}

Success: { "success": true }

Error 403 (family):
{
  "error": "Family login cannot change settings",
  "code": "FAMILY_READONLY"
}

Deactivate account:
{
  "deactivate": true
}
→ { "success": true, "deactivated": true } — then logout user

PART 3 — FAMILY ACCESS MANAGEMENT (Settings section)
================================================================================

Owner adds/removes family logins from Settings screen.
Max 3 family members per account.


--- GET list ---

GET /api/flutter/family-access
Headers: Authorization: Bearer <token>

Success 200:
{
  "members": [
    {
      "id": "uuid",
      "memberName": "Ramesh",
      "email": "father@gmail.com",
      "relationship": "Parent",
      "isActive": 1,
      "createdAt": "2026-05-01T..."
    }
  ],
  "maxAllowed": 3
}

Error 403 — family member cannot call this API


--- POST add family login ---

POST /api/flutter/family-access
Headers: Authorization: Bearer <token>

Body:
{
  "memberName": "Ramesh",
  "email": "father@gmail.com",
  "password": "family123",
  "relationship": "Parent"
}

relationship options: Parent | Sibling | Guardian | Other
password: minimum 6 characters

Success 201:
{
  "id": "uuid",
  "success": true,
  "member": {
    "id": "uuid",
    "memberName": "Ramesh",
    "email": "father@gmail.com",
    "relationship": "Parent",
    "isActive": true
  }
}

Errors:
  400 — missing fields / password too short
  400 — maximum 3 family logins (code: FAMILY_LIMIT)
  409 — email already used for family access


--- DELETE remove family login ---

DELETE /api/flutter/family-access?id={member_id}
Headers: Authorization: Bearer <token>

Success: { "success": true }

PART 4 — CHANGE PASSWORD (Settings → Change Password)
================================================================================

--- GET has password? ---

GET /api/flutter/auth/change-password
Headers: Authorization: Bearer <token>

Success: { "hasPassword": true }

Google-only users: hasPassword = false (skip current password field)


--- POST change password ---

POST /api/flutter/auth/change-password
Headers: Authorization: Bearer <token>

Body:
{
  "currentPassword": "oldpass123",
  "newPassword": "newpass456"
}

If hasPassword is false (Google user setting first password):
{
  "newPassword": "newpass456"
}

Success: { "success": true, "message": "Password updated successfully" }

Errors:
  400 — validation errors
  403 — family login blocked

--- Family login ---
final res = await http.post(
  Uri.parse('$baseUrl/api/flutter/auth/family-login'),
  headers: {'Content-Type': 'application/json'},
  body: jsonEncode({'email': email, 'password': password}),
);
final data = jsonDecode(res.body);
if (data['success'] == true) {
  final isFamily = data['user']['isFamilyLogin'] == true;
  await storage.saveToken(data['token']);
  await storage.saveUser(data['user']);
}

--- Load settings ---
final res = await http.get(
  Uri.parse('$baseUrl/api/flutter/settings'),
  headers: {'Authorization': 'Bearer $token'},
);
final settings = jsonDecode(res.body);
if (settings['readOnly'] == true) {
  // family user — show read-only or redirect
}

--- Save settings ---
await http.patch(
  Uri.parse('$baseUrl/api/flutter/settings'),
  headers: headers,
  body: jsonEncode({
    'privacy': privacyMap,
    'notifications': notificationsMap,
    'subscription': {'autoRenew': autoRenew},
  }),
);

--- Add family member ---
await http.post(
  Uri.parse('$baseUrl/api/flutter/family-access'),
  headers: headers,
  body: jsonEncode({
    'memberName': name,
    'email': email,
    'password': password,
    'relationship': 'Parent',
  }),
);
