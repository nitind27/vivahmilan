FEATURE 1 — REGISTRATION (Phone mandatory + disposable email block)
================================================================================

POST /api/flutter/auth/register

Body (JSON):
{
  "name": "Rahul Sharma",
  "email": "rahul@gmail.com",
  "phone": "+919876543210",      // REQUIRED now
  "password": "MyPass123"
}

Success 201:
{
  "success": true,
  "message": "Registration initiated. OTP sent to your email.",
  "email": "rahul@gmail.com"
}

Errors:
  400 — phone missing/invalid
  400 — disposable email (temp-mail blocked)
  409 — email or phone already registered

Flutter UI changes:
  - Phone field mandatory (not optional)
  - Show error if temp email used
  - Continue to OTP screen after success

Before user can submit profile, ALL items must pass:

  ✓ All required fields filled
  ✓ Valid phone on account
  ✓ At least 1 profile photo
  ✓ At least 1 family/lifestyle photo (in addition to profile photo)

  ✓ Profile marked 100% complete

Required profile fields:
  gender, dob, height, religion, education, profession, country, city, aboutMe

--- POST submit profile for verification ---

POST /api/flutter/profile/submit
Headers: Authorization: Bearer <token>
Body: {} (empty)

Success 200:
{
  "success": true,
  "message": "Profile submitted for admin review. You will be notified once approved.",
  "code": "PENDING_APPROVAL"
}

(User sees: "Profile submitted! We will notify you once verified.")
Note: API message may say "admin review" — show user-friendly text in Flutter UI.

Error 400 — PROFILE_INCOMPLETE:
{
  "error": "Profile incomplete. Fill all required fields before submitting.",
  "code": "PROFILE_INCOMPLETE",
  "missingFields": ["aboutMe"],
  "requiredFields": [...]
}

Error 400 — SUBMIT_REQUIREMENTS_NOT_MET:

PART 1 — FAMILY LOGIN
================================================================================

--- How it works ---

1. Member (owner) → Settings → Add family login (name, email, password, relationship)
2. Family member → Login screen → "Family Login" tab
3. Family enters THEIR email + password (not member's email)
4. JWT token issued with role = "FAMILY"
5. App shows banner: "Family Login — browsing {ownerName}'s profile"
6. All browse APIs use owner user id from token


--- POST Family Login ---

POST /api/flutter/auth/family-login
Body:
{
  "email": "father@gmail.com",
  "password": "family123"
}

Success 200:
{
  "success": true,
  "token": "<JWT>",
  "user": {
    "id": "<owner_user_id>",
    "name": "Ramesh (Parent)",
    "email": "father@gmail.com",
    "role": "FAMILY",
    "isFamilyLogin": true,
    "familyAccessId": "uuid",
    "memberName": "Ramesh",
    "relationship": "Parent",
    "ownerName": "Rahul Sharma",
    "ownerId": "<owner_user_id>",
    "isPremium": true,
    "premiumPlan": "GOLD",
    "adminVerified": true,
    "verificationBadge": false,
    "freeTrialActive": false,
    "freeTrialExpiry": null
  }
}

Errors:
  400 — email/password missing
  401 — invalid family credentials
  403 — owner account inactive


--- JWT payload (store in app state) ---

After family login, save:
  token
  user.role === "FAMILY"
  user.isFamilyLogin === true
  user.ownerName
  user.id === owner's user id (used for all API calls)


--- Flutter Login Screen UI ---

Two tabs on login page:
  [ Member Login ]  [ Family Login ]

Member tab → POST /api/flutter/auth/login
Family tab → POST /api/flutter/auth/family-login

After family login success:
  - Navigate to Dashboard (not onboarding)
  - Show persistent banner at top:
    "👨‍👩‍👧 Family mode — browsing Rahul's profile (read-only)"
  - Hide bottom nav items: Chat, Interests send, Premium purchase, Settings edit


--- What family CAN do ---

Detect family mode globally:
