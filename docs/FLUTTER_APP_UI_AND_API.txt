AUTH (all protected routes):
  Header: Authorization: Bearer <JWT>
  JWT from: login, verify-otp, google auth, family-login

PUBLIC (no token):
  GET  /api/flutter/home
  GET  /api/flutter/plans
  GET  /api/flutter/profile-options?grouped=1
  GET  /api/flutter/success-stories?published=1
  GET  /api/flutter/early-bird/status  (optional token for personalized offer)

WEB-ONLY (use WebView or skip in v1 app):
  Admin panel (all /api/admin/*)
  Welcome gate login page (/welcome.html)
  QR desktop login flow (/api/auth/qr-session) — optional v2
  KYC agent session (/kyc/[token]) — open in WebView if needed
  Legal static pages: /privacy, /terms, /refund, /cookies, /help, /contact
  Maintenance page UI (use GET /api/flutter/home → maintenance flag)
  Chatbot: /api/chatbot/* (same as web, not under /api/flutter/)

APP FLOW (recommended navigation)
================================================================================

  → GET /api/flutter/home (maintenance? → maintenance screen)

  Login → Register → Verify OTP → Onboarding → Dashboard

[Main tabs]
  1. Home (Dashboard)

SCREEN 5 — ONBOARDING (multi-step profile)
================================================================================
Web: /onboarding
Flutter UI (match web steps):
  Step 1: Basic — gender, DOB, height, marital status
  Step 2: Religion, community/caste (use CasteCommunitySelect logic)
  Step 3: Location — country/state/city
  Step 4: Education, profession, income
  Step 5: Family, partner preferences
  Step 6: About me
  Step 7: Photos — main photo + family photos
  Step 8: ID document upload
  Step 9: Review checklist → Submit for verification
  Optional: Intro video upload

Dropdown data:
  GET /api/flutter/profile-options?grouped=1
  → options.religion, options.caste_Hindu, options.education, etc.
  Hindu community: filter by category + region in UI (see web CasteCommunitySelect)
  “Other” caste: allow custom text value

API (EXISTS):
  GET  /api/flutter/profile
  PUT  /api/flutter/profile
  POST /api/flutter/upload/photo
  POST /api/flutter/upload/family-photo
  POST /api/flutter/upload/document
  GET  /api/flutter/profile/verification-checklist
  POST /api/flutter/profile/submit

API (NEW):
  POST /api/flutter/upload/intro-video     multipart field: video
  DELETE /api/flutter/upload/intro-video

Location helpers (EXISTS):
  GET /api/flutter/location/countries
  GET /api/flutter/location/states?countryCode=
  GET /api/flutter/location/cities?countryCode=&stateCode=
