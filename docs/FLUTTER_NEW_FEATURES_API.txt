FEATURE 1 — REGISTRATION (Phone mandatory + disposable email block)
================================================================================

POST /api/flutter/auth/register

Body (JSON):
{
  "name": "Rahul Sharma",
  "email": "rahul@gmail.com",
  "phone": "+919876543210",      // REQUIRED now
  "password": "MyPass123"
}

Success 201:
{
  "success": true,
  "message": "Registration initiated. OTP sent to your email.",
  "email": "rahul@gmail.com"
}

Errors:
  400 — phone missing/invalid
  400 — disposable email (temp-mail blocked)
  409 — email or phone already registered

Flutter UI changes:
  - Phone field mandatory (not optional)
  - Show error if temp email used
  - Continue to OTP screen after success

FEATURE 2 — PROFILE SUBMIT CHECKLIST (Before admin approval)
================================================================================

Before user can submit profile, ALL items must pass:

  ✓ All required fields filled
  ✓ Valid phone on account
  ✓ At least 1 profile photo
  ✓ At least 1 family/lifestyle photo (in addition to profile photo)
  ✓ ID document uploaded (Aadhaar/PAN/Passport etc.)
  ✓ Profile marked 100% complete

Required profile fields:
  gender, dob, height, religion, education, profession, country, city, aboutMe

Headers: Authorization: Bearer <token>
Body: {} (empty)

Success 200:
{
  "success": true,
  "message": "Profile submitted for admin review. You will be notified once approved.",
  "code": "PENDING_APPROVAL"
}

Error 400 — PROFILE_INCOMPLETE:

  "error": "Profile incomplete. Fill all required fields before submitting.",
  "code": "PROFILE_INCOMPLETE",

Error 400 — SUBMIT_REQUIREMENTS_NOT_MET:
{
  "error": "Your profile does not meet the verification requirements yet...",
  "code": "SUBMIT_REQUIREMENTS_NOT_MET",
  "checklist": [...],
  "errors": [...]
}


--- Upload APIs used for checklist ---

POST /api/flutter/upload/photo
  Content-Type: multipart/form-data
  Fields: photo (file), isMain ("true" / "false")

POST /api/flutter/upload/family-photo
  Content-Type: multipart/form-data
  Fields: photo (file), caption (optional), memberCount (optional)

POST /api/flutter/upload/document
  Content-Type: multipart/form-data
  Fields: document (file), type ("Aadhaar Card" | "PAN Card" | etc.)

FEATURE 4 — SEARCH: VERIFIED PROFILES ONLY
================================================================================

GET /api/flutter/search?verifiedOnly=1&page=1&limit=12

Query params (all optional):
  verifiedOnly=1 or verifiedOnly=true   ← NEW: only ID-verified badge profiles
  q, gender, religion, country, state, city
  education, profession, maritalStatus
  ageMin, ageMax, heightMin, heightMax
  page, limit

Headers: Authorization: Bearer <token>

Response includes verificationBadge on each user:
{
  "users": [
    {
      "id": "...",
      "name": "...",
      "verificationBadge": true,
      "profile": { ... },
      "photos": [ ... ]
    }
  ],
  "total": 42,
  "page": 1,
  "isPremium": true,
  "freeLimit": 5
}

Flutter UI:
  - Add toggle "Show verified profiles only"
  - Pass verifiedOnly=1 when toggle is ON
  - Show verified badge icon when verificationBadge === true

FEATURE 5 — REPORT ABUSE + AUTO-HIDE
================================================================================

POST /api/flutter/report
Headers: Authorization: Bearer <token>

Body:
{
  "targetId": "<reported_user_id>",
  "reason": "Fake profile",
  "details": "Optional description"
}

Success 201:
{
  "success": true,
  "id": "report-uuid",
  "message": "Report submitted successfully. Our team will review it shortly.",
  "autoHidden": false,
  "reportCount": 1
}

When target gets 3+ reports:
{
  "success": true,
  "message": "Report submitted. This profile has been temporarily hidden pending admin review due to multiple community reports.",
  "autoHidden": true,
  "reportCount": 3
}

Flutter: Show appropriate toast based on autoHidden flag.

FEATURE 6 — COUPON CODES (NEW / FIXED)
================================================================================

--- Quick validate (homepage / premium screen — no auth) ---

POST /api/flutter/coupons/validate
Body:
{
  "code": "SAVE20"
}

Success 200:
{
  "valid": true,
  "discountPct": 30,
  "code": "SAVE20"
}

Errors: 404 invalid, 410 expired or usage limit reached


--- Apply coupon with plan price (checkout screen — auth required) ---

POST /api/flutter/payment/apply-coupon
Headers: Authorization: Bearer <token>

Body:
{
  "code": "SAVE20",
  "planId": "GOLD",
  "months": 3,              // optional: 1, 3, 6, 0=lifetime
  "durationDays": 90        // optional: alternative to months
}

Success 200:
{
  "code": "SAVE20",
  "discountPct": 30,
  "originalPrice": 4497,
  "finalPrice": 3148,
  "durationDays": 90,
  "isAgentRef": false,
  "plan": "GOLD"
}

Also accepts agent referral codes (5% discount, isAgentRef: true)


--- Create payment order with coupon ---

POST /api/flutter/payment/create-order
Headers: Authorization: Bearer <token>

Body:
{
  "plan": "GOLD",
  "couponCode": "SAVE20",    // optional
  "months": 3,               // optional: 1, 3, 6, 0=lifetime
  "durationDays": 90         // optional
}

Success 200 (paid plan):
{
  "orderId": "MILAN_XXXXXXXX_1234567890",
  "paymentSessionId": "session_...",
  "orderAmount": 3148,
  "plan": "GOLD",
  "durationDays": 90,
  "couponApplied": "SAVE20"
}

Success 200 (100% discount — instant activation):
{
  "instantActivation": true,
  "plan": "GOLD",
  "orderAmount": 0,
  "premiumExpiry": "2026-08-28T..."
}

Flutter flow:
  1. User enters coupon → call apply-coupon → show discounted price
  2. User pays → call create-order with same couponCode
  3. Open Cashfree SDK with paymentSessionId
  4. After payment → call verify endpoint


--- Verify payment ---

POST /api/flutter/payment/verify
Headers: Authorization: Bearer <token>

Body:
{
  "orderId": "MILAN_XXXXXXXX_1234567890",
  "plan": "GOLD"
}

Success (paid):
{
  "status": "PAID",
  "isPremium": true,
  "premiumExpiry": "2026-08-28T..."
}

Note: Receipt email is sent automatically by backend after successful payment.

SAMPLE FLUTTER CODE SNIPPETS (Dart)

--- Auth header ---
final headers = {
  'Authorization': 'Bearer $token',
  'Content-Type': 'application/json',
};

--- Check verification checklist ---
final res = await http.get(
  Uri.parse('$baseUrl/api/flutter/profile/verification-checklist'),
  headers: headers,
);
final data = jsonDecode(res.body);
final canSubmit = data['eligible'] == true;

--- Apply coupon ---
final res = await http.post(
  Uri.parse('$baseUrl/api/flutter/payment/apply-coupon'),
  headers: headers,
  body: jsonEncode({'code': coupon, 'planId': 'GOLD', 'months': 3}),
);

--- Search verified only ---
final uri = Uri.parse('$baseUrl/api/flutter/search').replace(queryParameters: {
  'verifiedOnly': '1',
  'page': '1',
  'limit': '12',
});

--- Report profile ---
final res = await http.post(
  Uri.parse('$baseUrl/api/flutter/report'),
  headers: headers,
  body: jsonEncode({
    'targetId': userId,
    'reason': 'Fake profile',
    'details': 'Photos look copied',
  }),
);
if (jsonDecode(res.body)['autoHidden'] == true) {
  // show: profile hidden pending review
}
