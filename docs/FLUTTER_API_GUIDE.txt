================================================================================
FEATURE — MEMBER CHAT (User-to-User messaging)
================================================================================

Premium OR active free trial required for chat access.

403 reasons: no_access | premium_expired | trial_expired

--- List chat rooms ---

GET /api/flutter/chat?page=1&limit=20
Headers: Authorization: Bearer <token>

Success 200:
{
  "data": [
    {
      "id": "room-uuid",
      "userAId": "...",
      "userBId": "...",
      "createdAt": "...",
      "userA": { "id", "name", "isPremium", "profile", "photos", ... },
      "userB": { ... },
      "lastMessage": {
        "id", "content", "createdAt", "senderId",
        "type": "TEXT",
        "isRead": false
      }
    }
  ],
  "total": 5,
  "page": 1,
  "limit": 20,
  "hasMore": false
}

Error 403:
{ "error": "Chat access required", "hasAccess": false, "reason": "no_access" }


--- Start chat / first message ---

POST /api/flutter/chat
Body (text):
{ "receiverId": "<user_id>", "content": "Hello!", "type": "TEXT" }

Body (location):
{
  "receiverId": "<user_id>",
  "type": "LOCATION",
  "latitude": 19.0760,
  "longitude": 72.8777,
  "locationType": "static",
  "locationExpiry": "2026-05-28T12:00:00.000Z"
}

Success 201: message object + roomId


--- Get messages ---

GET /api/flutter/chat/{roomId}?page=1&limit=20
GET /api/flutter/chat/{roomId}?before=2026-05-28T10:00:00.000Z&limit=20

Success 200:
{ "data": [...], "total": 45, "page": 1, "limit": 20, "hasMore": true }

Opening a room auto-marks received messages as read.


--- Send in existing room ---

POST /api/flutter/chat/{roomId}

Text: { "content": "Hi", "type": "TEXT" }

Image/PDF (multipart): file, type ("IMAGE" or "DOCUMENT")
  IMAGE: JPG/PNG/WEBP/GIF, max 15MB
  DOCUMENT: PDF, max 15MB

Location:
{
  "type": "LOCATION",
  "latitude": 19.07,
  "longitude": 72.87,
  "locationType": "live",
  "locationExpiry": "2026-05-28T12:30:00.000Z"
}


--- Live location ---

GET  /api/flutter/chat/location/{msgId}
PATCH /api/flutter/chat/location/{msgId}
Body: { "latitude": 19.08, "longitude": 72.88 }


--- Unread count ---

GET /api/flutter/chat/unread

Success: { "total": 3, "perRoom": { "room-uuid-1": 2 } }


--- Real-time (Socket.IO) ---

Connect: wss://vivahdwar.com  path: /api/socket
Auth: { token: "<JWT>" }

EMIT: room:join, room:leave, message:send, message:read,
      typing:start, typing:stop, location:update, user:online

LISTEN: message:receive, message:read, typing:start, typing:stop,
        location:update, users:online

Package: socket_io_client — REST for history, socket for live.


================================================================================
FEATURE — SUPPORT CHATBOT (AI Help + Live Support)
================================================================================

In-app help — FAQ, plans, payment, profile. Free for all users.
APIs: /api/chatbot/* (NOT under /api/flutter/)

--- Init ---

POST /api/chatbot/init
Body: {}
Success: { "ok": true }


--- Session ---

GET /api/chatbot/session?sessionId={guestSessionId}

POST /api/chatbot/session
Body: { "action": "new", "userId": "<optional>" }

Success:
{
  "ok": true,
  "sessionId": "uuid",
  "status": "bot",
  "messages": [...],
  "storageKey": "vd-support-session"
}

Actions:
  { "action": "escalate", "sessionId": "...", "userId": "..." }
  { "action": "attach", "sessionId": "...", "userId": "..." }
  { "action": "end", "sessionId": "..." }


--- Send message ---

POST /api/chatbot/message
Body:
{
  "sessionId": "uuid-or-null",
  "message": "What are premium plans?",
  "userId": "<optional>"
}

Success:
{
  "sessionId": "uuid",
  "status": "bot",
  "botReply": "...",
  "intent": "premium",
  "followUps": [
    { "label": "View Plans", "text": "premium plans" },
    { "label": "Talk to Agent", "text": "__escalate__" }
  ],
  "confidence": 0.85,
  "suggestLiveAgent": false
}

When status is "live" — poll GET /api/chatbot/message?sessionId= every 3-5 sec.
"__escalate__" followUp → POST session action escalate.


--- History ---

GET /api/chatbot/message?sessionId={sessionId}

Intents: greeting, premium, payment, profile, verification, safety,
         refund, login, search, agent, fallback
Languages: English + Hindi
