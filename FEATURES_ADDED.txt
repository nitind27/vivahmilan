================================================================================
  PEHLE SETUP (Testing se pehle)
================================================================================

1. App chalao:
   npm run dev
   (Default: http://localhost:3006 — apne .env ke NEXTAUTH_URL ke hisaab se)

2. Database tables auto-create hongi jab pehli baar feature use karoge.
   Agar confirm karna ho to yeh command chalao:
   node scripts/run-ensure-feature-tables.js
   (Production DB ke liye .env.production use hota hai)

3. .env mein yeh variables honi chahiye:
   - DATABASE_* (MySQL connection)
   - NEXTAUTH_SECRET, NEXTAUTH_URL
   - EMAIL_SERVER_* (email alerts ke liye)
   - CRON_SECRET (cron jobs ke liye)
   - VAPID_PUBLIC_KEY / VAPID_PRIVATE_KEY (web push ke liye)

4. Premium features test karne ke liye:
   Admin → Plans (/admin/plans) par plan permissions enable karo:
   - canSeeWhoViewed
   - aiMatchScore
   - kundaliMatchPdf

5. Test accounts:
   - Normal user account (registered + approved)
   - Admin account (role = ADMIN)
   - Doosra user account (match / interest test ke liye)

A1. SAVED SEARCHES
--------------------------------------------------------------------------------
Kya hai:
  Search filters save karo, baad mein load karo, delete karo.

Kahan:
  /search

Kaise test karo:
  1. Login karo → /search par jao
  2. Filters lagao (city, religion, age, etc.)
  3. "Save Search" button dabao → naam do → save
  4. Saved searches list se wapas load karo — filters restore hone chahiye
  5. Delete icon se saved search hatao

Expected:
  - Save / Load / Delete sab kaam kare
  - API: GET/POST/DELETE /api/saved-searches
